## What is Skeletal Dismemberment

Dismemberment</br>
/dɪsˈmɛmbəm(ə)nt/<br/>
Noun<br/>
1.<br/>
The action of cutting off a person's or animal's limbs.<br/>
"Graphic pictures of torture and dismemberment"<br/>
<br/>

This plugin mimics limb severance with a minimal gore level by spawning limbs and particle VFX on seperation.
